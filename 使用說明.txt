Vorax 輔助器 中文版 使用說明
==============================

在渴癮症（手術準備）畫面，它會標示建議選擇的卡牌和培養槽。
只讀取畫面，不會替你操作遊戲。非官方版本。

【第一次使用】
1. 遊戲中按 Esc →「帳號相關」→「開啟日誌」，然後登出再登入。
2. 遊戲使用無邊框或視窗模式（不要用獨佔全螢幕）。
3. 遊戲日誌的位置會自動尋找，不必設定。
   若系統匣顯示「找不到遊戲日誌」：先開啟遊戲，工具會從遊戲的安裝位置找到它；
   仍找不到時，用記事本打開 start-zh.bat，在第 5 行 GAMELOG= 後面填入：
   遊戲資料夾\Game\UE_game\TorchLight\Saved\Logs\UE_game.log

【開啟與關閉】
- 開啟：點兩下 start-zh.bat，工具會在右下角系統匣執行（Windows 11 可能收在「^」裡面）。
  vorax-overlay.exe 就是中文版的主程式（檔名和原作者相同），平常點 start-zh.bat 即可。
- 關閉：系統匣圖示按右鍵 →「結束」，或按 Ctrl + Alt + Q。
- 第一次執行若出現「Windows 已保護您的電腦」，點「其他資訊」→「仍要執行」。

【核對讀取結果】
工具會顯示它讀到的內容，請和遊戲畫面對照：
- 每格培養槽的名字下方有一個小框，例如「骨 15×12」：
  蟲＝蠱蟲、骨＝骨衛兵、異＝異魔、覺＝覺醒者，後面是活性×數量。
  文字顏色代表稀有度，和遊戲的名字顏色相同：白色＝普通、藍色＝魔法、金色＝稀有、紅色＝首領。
  灰色「空」＝空格；橘色「？」＝沒讀到。
- 提示框下方一行顯示讀到的卡（由左到右編號），例如「卡：1 空心脊髓溶液｜2 生骨藥粉｜3 ？」。
若有讀錯（例如有怪物卻顯示「空」、數字或顏色不同），那一步的建議就不可靠，
請自行判斷，並用 start-zh-debug.bat 收集畫面回報。
按 Ctrl + Alt + D 可以隱藏或顯示這些內容（每次開啟工具時預設顯示）。

【刷新次數】
刷新按鈕右邊會顯示工具讀到的剩餘刷新次數，例如「刷新 2」。
如果和遊戲不同，或顯示橘色「刷新 ？」（沒讀到），工具會以為沒有刷新次數，
那一步的建議（特別是該不該刷新）就不可靠。

【模式】（系統匣「模式」切換）
- 保守（原作者）：預設。只追求達到 840k（彩箱）的機率，接近 840k 時常常不再加分。
- 衝分：彩箱機率差不多時，選平均分數較高的。電腦模擬中彩箱機率和平均分數都較高，
  但翻車時分數可能較低。提示框會多顯示「平均 N 萬」。

【對局紀錄】（系統匣「對局紀錄」）
- 可以查看每一局每回合的建議。拖曳右邊、下邊或右下角可改變大小，Ctrl + 滑鼠滾輪可縮放。
- 最上方的「實戰統計」依模式列出打完的局數、彩箱局數、開局預計機率與平均分數，
  可以檢查工具的預計和實戰是否相符。

【讀不到、讀錯時怎麼辦】（先一步一步試，仍然不行再回報）
1. 完全沒有提示：看系統匣（可能收在「^」裡）有沒有工具圖示；沒有就重新點 start-zh.bat，
   有的話按 Ctrl + Alt + V 確認提示沒被隱藏。遊戲要在最前面，不能是獨佔全螢幕。
2. 系統匣顯示「找不到遊戲日誌」：照系統匣的說明做。在此之前可按 Ctrl + Alt + X 手動讀取。
3. 提示框寫「未讀到：第 N 張卡」或卡名是「？」：
   - 把滑鼠移開卡牌（移到畫面空白處）。滑鼠指著卡時卡會升起，標題可能被擋住。
   - 等卡牌完全飛到定位（動畫中工具會暫停提示）。
   - 按 Ctrl + Alt + X 重新讀取。
4. 培養槽的小框或刷新次數和遊戲不同：按 Ctrl + Alt + X 重新讀取；
   仍然錯的話，那一步的建議不可靠，請自行判斷並回報。
5. 一局中途才開啟或重新開啟工具：右上角已擁有的手術用具可能讀錯，建議每局開始前開啟。
6. 以上都試過仍有問題：改用 start-zh-debug.bat 開啟，重現一次，再到 GitHub 的 Issues 回報。

【注意】
- 有新版本時系統匣會提示，點「立即更新」即可（會下載本專案的中文版並檢查檔案）。
  若你用的是 v0.2.2-zh.1，請到 GitHub 手動下載新版一次；zh.1 的「更新到 v…」提示是原作者英文版，不要點。
- 選單的「文字」可切換繁體／簡體（預設「自動」，跟隨遊戲的文字）。
- 最後 3 回合（手術方案）不會給建議，請自行決定。
- 提示框出現「未讀到：第 2 張卡、第 3 格」之類的字，代表那張卡、那一格沒讀到。
  工具會每隔 1 秒自動重新讀取，最多 2 次，通常不用理會。
  如果提示一直沒有消失，可以按 Ctrl + Alt + X 再讀一次；仍然出現的話，那一步請自行判斷。
- 提示框出現「不在資料內，請自行判斷」：那張卡（例如「解剖浸液：病軀」）原作者的資料裡沒有，
  工具無法計算它，建議只在其他卡之間比較。要不要選它，請自行判斷。
- 有問題時改用 start-zh-debug.bat 開啟，畫面會存在 frames 資料夾。
- 回報問題：到 GitHub 專案的 Issues 選「問題回報」，附上記錄檔 overlay.log
  （在檔案總管網址列輸入 %APPDATA%\VoraxRs）和 frames 裡檔名有 reread 的圖片。
- 建議解析度：2560×1440 視窗、3840×2160 視窗化全螢幕。不要使用獨佔全螢幕。
- 建議在每局開始前開啟工具；一局中途才開啟時，右上角已擁有的手術用具可能讀錯。
